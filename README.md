# 🔬 Data Intelligence Lab

> **100% Offline · Zero Telemetry · Confidential Data Safe**

A private, AI-powered data analysis platform that runs entirely on your machine. Upload a CSV, Excel, or PDF — get instant AI-generated insights, interactive visualisations, ML-based anomaly detection, and a downloadable PDF report. **Your data never leaves your machine.**

---

## ✨ Features

| Feature | Detail |
|---|---|
| 📊 **BI Dashboard** | Auto-analysis, Isolation Forest + IQR anomaly detection, AI explanations, downloadable PDF report |
| 💬 **Data Chat** | Natural-language transformations, chart generation, and data Q&A powered by any local Ollama model |
| 📄 **PDF Analyser** | Grounded summarisation and Q&A on uploaded PDFs — no hallucinated figures |
| 🔒 **Privacy-First** | Sandboxed `exec()`, blocked dangerous imports, Streamlit telemetry fully disabled, Ollama bound to `127.0.0.1` only |
| 🧠 **Any Ollama Model** | Works with `llama3`, `mistral`, `gemma`, `phi`, `deepseek`, `qwen`, and more |
| 🛡 **Hardened exec()** | LLM-generated code runs in a whitelist-only builtins sandbox with `sys.meta_path` import blocker |

## ⚙️ Setup (one-time)

### Step 1 — Install Python packages
```bash
pip install -r requirements.txt
```

Or manually:
```bash
pip install streamlit>=1.32.0 ollama>=0.1.8 pandas numpy openpyxl PyPDF2 \
            plotly pyarrow scikit-learn fpdf2
```

### Step 2 — Install Ollama
Download from **https://ollama.com** (no account needed, fully offline after install).

### Step 3 — Pull a model
```bash
ollama pull llama3       # recommended — fast and capable
# or
ollama pull mistral      # good alternative
# or
ollama pull gemma3       # lightweight option
```

## 🚀 How to Run

### Recommended — secure launcher (macOS / Linux):
```bash
chmod +x run.sh
./run.sh
```
The launcher forces Ollama to bind `127.0.0.1:11434` only, disables telemetry, and starts Streamlit on `127.0.0.1:8501`.

### Manual (all platforms):
```bash
ollama serve &
streamlit run app.py \
    --server.address 127.0.0.1 \
    --browser.gatherUsageStats false
```

Then open **http://127.0.0.1:8501** in your browser.

## 🖥 Pages

### 🏠 Home (`app.py`)
- Upload CSV / Excel / PDF or load sample data
- Instant dataset overview: row/column counts, quality %, missing values, duplicate count
- Correlation matrix, missing-value bar chart, dtype audit tab
- Auto-analysis report generated by the LLM on file load
- Full chat interface for data transformations and questions

### 📊 BI Anomaly Dashboard (`pages/1_Dashboard.py`)
- **Isolation Forest** (ML): detects multi-dimensional anomalies using `sklearn`
- **IQR per column**: flags extreme statistical outliers with human-readable thresholds
- Interactive Plotly charts: anomaly score distribution, column-level scatter plots
- AI-generated plain-English explanations for each anomalous column
- **Download a professional PDF analyst report** (branded, multi-page via `fpdf2`)

### 💬 Data Chat (`pages/2_Chat.py`)
- Dedicated chat page — load any CSV / Excel without leaving the page
- Intent-aware prompts: auto-classifies as `modify`, `chart`, or `question`
- Shows generated Python code in an expander for full transparency
- Dataset updates in-place; download modified CSV at any time

### 📄 PDF Analyser (`pages/3_PDF_Analyser.py`)
- Upload any PDF; the app extracts text and pre-computes facts (page count, word count, key figures)
- Grounded summarisation — the LLM is given only extracted facts so it cannot hallucinate statistics
- Follow-up Q&A chat with the same grounding constraints

## 🔒 Security Guarantees

| What | How |
|---|---|
| **No data sent anywhere** | Zero outbound network calls in app code |
| **Streamlit telemetry** | Disabled via `config.toml` + env vars + CLI flags |
| **Ollama LAN exposure** | `run.sh` forces `OLLAMA_HOST=127.0.0.1:11434` |
| **exec() sandbox** | `__builtins__` whitelisted; `os/sys/socket/subprocess/…` blocked via `sys.meta_path` |
| **Fonts** | OS system fonts only — no Google Fonts CDN calls |
| **Data on disk** | Never written; stays in Python RAM only |
| **PDF stats grounding** | Evidence pre-computed and injected; LLM cannot invent numbers |

### Verify yourself (macOS / Linux — while app is running):
```bash
# Should return NOTHING if fully private
lsof -i -n -P | grep -E "streamlit|ollama" | grep -v "127.0.0.1\|LISTEN"
```

## 🧪 Architecture — Anti-Hallucination Design

```
Your file  →  file_loader.py  →  evidence.py (compute all stats)
                                        │
                               prompts.py (inject exact numbers)
                                        │
                               llm.py (Ollama, local only)
                                        │
                               sandbox.py (safe exec for code)
                                        │
                               Streamlit UI (render + download)
```

The LLM **never sees raw data rows** directly — it receives only the pre-computed statistical summary. This eliminates the most common source of AI hallucination in data tools.

## 🛠 Troubleshooting

**"Ollama offline" badge in sidebar**
```bash
ollama serve          # start Ollama
ollama pull llama3    # pull the model if not done yet
```
Then refresh the page.

**"File load error" on upload**
- Ensure the file is a valid CSV, XLSX, or PDF
- Excel files must have data in the first sheet

**Chart request shows an error**
- Try rephrasing: *"Plot a bar chart of sales by region using plotly"*
- The LLM sometimes needs explicit column names; try asking *"Show me the column names"* first

**Transformation didn't apply**
- Check the **Generated Code** expander — verify the column names match your data
- Try: *"Show me the column names"* first
